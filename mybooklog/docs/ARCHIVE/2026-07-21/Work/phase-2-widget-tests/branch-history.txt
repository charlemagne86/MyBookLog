=== TECHNICAL DECISIONS ===

1. Mock Factories (not generic pumpTestWidget):
   - Reason: Each screen has unique dependencies
   - Result: More readable, type-safe mock returns

2. MockSession instead of real Session:
   - Reason: Tests only care if session is null/not-null
   - Result: Simpler test setup

3. Completer for async observation:
   - Reason: Can control when operations complete
   - Result: Can observe loading states in isolation

4. Comprehensive business logic documentation:
   - Reason: Why each test matters (not just what it tests)
   - Result: Future maintainers understand intent
